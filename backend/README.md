# Staff Attendance Portal

## Project Description

This is a Staff Attendance Portal developed using FastAPI and SQLite.

## Technologies Used

- Python
- FastAPI
- SQLite
- HTML
- CSS

## Features

- Add Attendance
- View Attendance
- Update Attendance
- Delete Attendance
- Search Employee
- Dashboard
- Leave Management
- Export CSV
- Admin Login

## Project Structure

```
STAFF-ATTENDANCE-PORTAL
│
├── backend
│   ├── main.py
│   ├── attendance.db
│   ├── requirements.txt
│
├── frontend
│
└── README.md
```

## Run Project

```bash
cd backend
uvicorn main:app --reload
```

Open Browser:

```
http://127.0.0.1:8000/frontend
```
